# Data

**The open datasets are included** in `data/raw/` (about 18 MB) so the app runs straight after cloning, even offline. Licence and credit files sit next to the data (`data/raw/*/LICENSE.txt`). Everything else in `data/` is generated by code.

## 1. The open datasets (already included; the script can re-download them)

To re-download from the official sources and re-verify checksums, delete `data/raw/` and run:

```bash
python scripts/download_data.py
```

| Dataset | Files fetched | Licence | Used for |
|---|---|---|---|
| CDC **NHANES 2017–March 2020 pre-pandemic** (https://wwwn.cdc.gov/nchs/nhanes/) | `P_DEMO, P_BMX, P_BPXO, P_GHB, P_GLU, P_BIOPRO, P_TCHOL, P_HDL, P_TRIGLY, P_SLQ, P_DIQ, P_BPQ` (.xpt) → `data/raw/nhanes/` | Public domain (U.S. government) | Calibrating the synthetic EHR (age, sex, BMI, waist, BP, HbA1c, fasting glucose, eGFR, lipids, sleep hours, diagnosis history) |
| **LifeSnaps** Fitbit dataset (https://zenodo.org/records/7229547) | only `daily_fitbit_sema_df_unprocessed.csv` (2 MB), extracted from the 615 MB archive with HTTP range requests → `data/raw/lifesnaps/` | CC BY 4.0 | Personal ranges of sleep, HRV, resting HR, steps; real-data validation |

Genetic allele frequencies (1000 Genomes phase 3, South Asian): TCF7L2 rs7903146-T = 0.299,
MTNR1B rs10830963-G = 0.426 — verified via the Ensembl REST API (`/variation/human/<rsid>?pops=1`).

**Not used:** MIMIC-IV, NSRR/SHHS/MESA (credentialed), `simglucose` (Type-1 only), any personal health data.

If a download fails, the simulator automatically falls back to published summary statistics
(`src/calibration.py`) and says so in `reports/results.md`.

## 2. Generate the virtual cohort + train everything (~20 s)

```bash
python -m src.pipeline
```

Creates `data/processed/*.parquet` (git-ignored):

| File | Contents |
|---|---|
| `profiles.parquet` | 300 synthetic EHRs (3 demo personas A/B/C + 297 generated) |
| `nights.parquet` | nightly sleep summary, HRV, resting HR, SpO₂ dips (ODI), steps — observed (with ~5% missing nights) and `*_true` |
| `hypnograms.parquet` | 5-minute sleep stages for every night |
| `cgm.parquet` | 5-minute CGM for 21 days × 300 patients (1.8 M rows, ~5% dropout) |
| `meals.parquet` | meal log (time, carbs) |
| `daily.parquet` | latent insulin sensitivity, sleep debt, morning SBP, labels |
| `features_nextday.parquet`, `samples_2h.parquet` | model inputs |

Wearable field names mimic a consumer export (`sleep_stage`, `resting_heart_rate`, `hrv_rmssd`, `steps`, `spo2`/ODI, `glucose_mg_dl`).

**All patient data is simulated.** Names and cities are fictional.
